# Сайт "История города Горловка"

## Назначение проекта
Проект выполнен в рамках лабораторной работы по веб-программированию.  
Цель — разработка многостраничного сайта о городе Горловка с использованием HTML5 и CSS3.  
Сайт знакомит посетителей с историей города, культурой, инфраструктурой, а также содержит информацию о разработчике и форму обратной связи.

---

## Использованные технологии
- **HTML5** — разметка страниц, семантические теги (`header`, `footer`, `nav`, `section`, `article`, `main`, `time`, `progress` и др.).
- **CSS3** — оформление элементов, позиционирование, обтекание, селекторы, псевдоклассы и псевдоэлементы.
- **XAMPP / OpenServer** (по желанию) — для локального запуска проекта.
- **Google Chrome** — для тестирования отображения сайта.

---

## Структура страниц
Сайт состоит из 6 основных страниц:
1. **Главная (`main.html`)** — общее описание города, фотографии, блок с актуальными событиями.  
2. **История (`history.html`)** — таблица с ключевыми историческими событиями.  
3. **Инфраструктура (`infrastr.html`)** — описание транспорта и карты города.  
4. **Культура и искусство (`culture.html`)** — информация о театрах, музеях, фестивалях, известных деятелях культуры.  
5. **Форма обратной связи (`contact.html`)** — поля для имени, email и сообщения, валидация формы средствами HTML5.  
6. **О разработчике (`about.html`)** — фотография, краткая биография, навыки в виде диаграммы прогресса.

Общие элементы:
- **Шапка сайта (`header`)** с логотипом и навигацией.  
- **Подвал (`footer`)** с контактной информацией и копирайтом.  
- Все страницы связаны между собой через меню навигации.

## Как запустить сайт локально
1. Скачайте проект с GitHub или сохраните все файлы на компьютер.  
2. Разместите папку проекта в корневом каталоге веб-сервера:  
   - Для **XAMPP** — в папку `htdocs`.  
   - Для **OpenServer** — в папку `domains`.  
3. Запустите сервер (Apache).  
4. Откройте браузер (например, Google Chrome) и перейдите по адресу:  
http://localhost/название_папки_проекта/main.html
5. Сайт будет доступен для просмотра и тестирования.
